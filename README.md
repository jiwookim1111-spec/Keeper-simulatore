# Keeper 3D Android 홈 화면 설치용 PWA

이 폴더는 Android Chrome에서 홈 화면에 설치할 수 있는 PWA 패키지입니다.

## 설치 방법
1. 폴더의 모든 파일을 HTTPS를 지원하는 웹 호스팅에 업로드합니다. (예: GitHub Pages)
2. Android 휴대폰에서 배포된 주소를 Chrome으로 엽니다.
3. 메뉴(⋮)에서 `앱 설치` 또는 `홈 화면에 추가`를 누릅니다.
4. 홈 화면의 Keeper 3D 아이콘으로 실행합니다.

## 참고
- PWA 설치는 HTTPS 또는 localhost 환경에서만 지원됩니다.
- 이 패키지는 APK가 아닙니다. 이 채팅에서 직접 휴대폰에 설치하거나 홈 화면 아이콘을 생성할 수는 없습니다.
- 현재는 터치 조작, 가로 화면, 랜덤 슈팅, 간단한 골키퍼/공 시각화가 포함된 초기 플레이어블 웹앱입니다.
- 정식 3D 엔진 기반의 현실적 그래픽, 정교한 애니메이션, 실제 APK 패키징은 추가 개발이 필요합니다.
